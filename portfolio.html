1. AI Financial Investment Assistant

Developing a financial analysis application that analyses investment portfolios using live and historical market data. The application combines financial calculations, portfolio analytics and AI-generated explanations to help users understand investment performance and risk.

  • Integrated Alpha Vantage and yfinance for live and historical market data
  • Implemented portfolio returns, volatility, Sharpe ratio, beta and maximum drawdown calculations
  • Added correlation analysis and financial risk-analysis functionality
  • Processed financial datasets using pandas and NumPy
  • Built interactive Streamlit dashboards for portfolio analysis and reporting
  • Integrated Google Gemini and LangChain for natural-language explanations of analytical results
  • Designed the system so financial calculations are performed programmatically rather than by the AI model
  • Used Git and GitHub throughout development

Tech: Python, pandas, NumPy, Streamlit, Alpha Vantage, yfinance, Google Gemini API, LangChain, Git, GitHub
